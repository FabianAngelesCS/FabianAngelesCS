## 👨‍💻 About Me

I'm a **Full Stack Developer** based in **Oaxaca, Mexico** 🇲🇽. My background in economics taught me to understand *why* a system needs to exist before thinking about *how* to build it — that perspective shapes everything I build.

I don't specialize in a single stack. I let the problem define the tool: **Python** for backend systems and APIs, **C#** for Windows desktop apps with AI integration, **Java** for standalone client applications.

## 💼 Featured Projects

### 🔒 PraditecManager — Managed Print Services System
> *Private repository — client project*

Desktop management system for a government-contracted MPS company handling **350–450 printers monthly** for a major public education institution in Oaxaca.

**What it does:**
- Loads scanned PDFs and extracts meter readings via **Azure AI Document Intelligence (OCR)**
- Calculates monthly billing per equipment based on contract type (fixed, per-use, unlimited)
- Generates billing PDFs per client and uploads them to **Google Drive** organized by month

**Tech Stack:** `C#` · `.NET 8` · `ASP.NET Core Web API` · `WPF` · `MVVM` · `Entity Framework Core` · `SQL Server` · `Azure AI` · `PDFsharp` · `Google Drive API`
